نظام إدارة وتحليل نتائج الطلاب

هذا المشروع يحلل درجات الطلاب باستخدام Classes ودوال المصفوفات (map, filter, reduce). تم تشغيل الكود تلقائيًا، وجميع النتائج تظهر في الـ Console.

كيف تفتح الـ Console؟

  1. على الويندوز اضغطF12 أو fn + f12
  2. على الماك اضغط: Cmd + Option + J
  3. اختر تبويب Console

ماذا ستجد هناك؟

  • تقرير كل طالب: الاسم، المتوسط، التقدير، النتيجة
  • مصفوفة الطلاب المتعثرين بعد الرأفة
  • متوسط المتعثرين بعد التعديل

إذا كانت الـ Console فارغة، حدّث الصفحة بعد فتحها.
